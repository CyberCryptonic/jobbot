How this works

When a form asks something this bank doesn't cover, the system follows one rule: optional → leave blank; required but safely inferable → infer and log it; required and unknown → skip the job and record the question here as a gap. Answer a gap once and every future form that asks it fills automatically.

Sections marked attestation (salary, experience years, clearance) are answers on signed forms — edit them only when the truth changes. Every edit is logged and the file is backed up daily before the first change.
